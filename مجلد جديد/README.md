# كيرم أونلاين

هذه نسخة العمل المعتمدة للعبة.

## التشغيل

```bash
npm install
npm start
```

ثم افتح:

`http://localhost:8080/الرئيسية.html`

## الملفات الأساسية

- `الرئيسية.html` و`الرئيسية.css` و`الرئيسية.js`: واجهة اللعبة.
- `online.js`: الاتصال بالسيرفر.
- `server.js`: الحسابات والغرف والرسائل والأصدقاء.
- `assets-references/`: الصور المرجعية المحفوظة.
